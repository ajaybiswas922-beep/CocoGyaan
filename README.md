## GitHub Pages par live kaise karein

1. GitHub par naya **public** repository banao (jaise `gst-tds-itr-toolkit`).
2. `index.html` aur `README.md` upload karo (**Add file → Upload files → Commit**).
3. Repo ki **Settings → Pages** mein jao.
4. **Source:** "Deploy from a branch" → Branch: `main` → Folder: `/ (root)` → **Save**.
5. 1–2 minute baad page live: `https://<aapka-username>.github.io/gst-tds-itr-toolkit/`
